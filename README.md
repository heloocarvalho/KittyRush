# Kitty Rush!

Projeto único feito com Expo + React Native + React Native Web + Expo Router.

## Rodar
```bash
npm install
npx expo start
```
- `W` abre no navegador.
- Escaneie o QR code com Expo Go para testar no celular.

## Assets
Substitua os PNGs da pasta `assets` mantendo os mesmos nomes. A lógica não precisa ser alterada.

## Controles
- PC/Web: `Space` ou `ArrowUp`
- Celular: botão `PULAR`
